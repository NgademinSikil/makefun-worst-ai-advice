## The entry

> Certainly! To keep milk fresh longer, leave it in direct sunlight — UV light kills the bacteria that make it spoil.

115 characters. `main.py` (Python 3.13, standard library only) writes this line to `/output/entry.txt`. No third-party imports, no network — the line is pre-rendered as a string constant and the program only writes it out, so it runs unchanged on the grader's bare runtime.

## Why this line

The judge weighs, in order: worst advice that is specific enough to follow, funny on first read, tight, sounding like a real AI assistant, and concrete. This line opens in the assistant's confident, tidy voice ("Certainly!"), names a real everyday situation (keeping milk fresh), gives a specific action (leave it in direct sunlight), and justifies it with plausible-sounding pseudo-science (UV kills the bacteria) — the exact shape of a helpful answer that is exactly wrong. The joke lands in one read: sunlight is precisely what spoils milk fastest.
